# 后续迭代

## 当前发布准备

0.3.0 已实现状态纯数据读取、API 认证、私有文件、逐协议恢复及失败回滚、启动器数据保护、用户态卸载清理、可信构建输入与发布文档。默认仅 OpenAI 相关域名走代理，其余直连，不内置地理数据库或网页面板。

自动化验证与真实系统验收必须分开记录。下一步先完成[发布流程](releasing.md)中的 GitHub CI、干净 Ubuntu 虚拟机安装/重启/升级/卸载验收，再公开稳定版。

## P1：首版反馈后优先考虑

- 将服务登录自启与当前代理开关分开设置；现在 start 同时启用自启，stop 同时取消。
- GUI 中提供独立的应用选择与重新适配入口、订阅更新预览和失败原因。
- 企业域名与 DNS 绕过设置，更新订阅后保留；需要真实企业 VPN/DNS 验证。
- 日志导出前预览、内部域名与地址自定义脱敏。
- 为发布产物添加维护者签名或 GitHub attestation，提供公开验证方法。

## P2：有明确需求后再扩展

- 更多发行版、桌面、架构；每增加一个目标都补完整生命周期验收。
- 节点手动选择保护期、最近探测结果及连接规则解释。
- 桌面快捷键、轻量流量概览。

不把多订阅聚合、TUN、跨平台迁移和复杂规则编辑器作为轻量首版的前置任务。
