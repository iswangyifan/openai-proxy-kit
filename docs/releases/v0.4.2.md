适用于 **Ubuntu 24.04 / GNOME / amd64（Intel、AMD 64 位）**。这是独立 Linux 软件包，内置 mihomo 和 Python 路由引擎，无需 Node.js 或额外 controller 工程。其他发行版、桌面和架构尚未认证。

### 下载和安装

普通用户下载下方附件中的：

- `openai-proxy-kit_0.4.2_amd64.deb`：安装包。
- `SHA256SUMS`：完整性校验文件。
- `openai-proxy-kit-0.4.2-guide.html`：图片已内嵌的离线图文教程，下载后用浏览器打开。

在下载目录打开终端：

```bash
sha256sum --ignore-missing -c SHA256SUMS &&
sudo apt install ./openai-proxy-kit_0.4.2_amd64.deb
```

然后从应用菜单打开 **Proxy Kit**，按教程填写自己的 Clash YAML 订阅。软件不附带订阅、节点凭据或 OpenAI 账号。已有用户也使用上述安装命令升级，保留现有网站设置和订阅配置。

SHA256 用于完整性校验，本版没有独立数字签名。系统依赖由 apt 安装；需要能访问相应 Ubuntu 软件源。

### 本版功能

- 默认 OpenAI / ChatGPT 走代理，其他流量直连；可勾选 GitHub、YouTube 或添加需要代理的公网域名。
- 节点页新增“检测 ChatGPT”：默认显示五分钟内公开端点可达的节点，按完整检测耗时排序，也可查看全部候选。
- 区分未检测、检测失败、入口不可用和过期结果；检测不切换当前节点。
- “高级管理”自动连接本机页面并更新浏览器保存的旧管理密钥，无需手填地址或 secret。此入口需要当前部署已有兼容的 MetaCubeXD 页面；日常切换节点无需使用它。
- 提供 GUI、托盘、实时日志、诊断、系统代理恢复及失败回滚。

### 验证范围与边界

本版已完成本机安装升级、真实公开端点检测、GTK 页面与按钮操作、浏览器自动认证及旧密钥恢复验证；远端自动发布流程会在构建和自动化检查通过后才公开附件。

0.3.0 的完整 Ubuntu 24.04/GNOME 虚拟机生命周期验收是历史记录，**0.4.2 没有完整重跑该虚拟机流程**，不能把它当作本版全部场景均已认证。公开端点可达不保证账号登录、对话、视频播放或全部 API 业务成功。软件不接管系统 DNS，不启用 TUN；应用需要实际使用代理，终端 Git 和 SSH 不会自动适配。

公司内网域名应保持直连，不要填进“代理网站”的自定义域名。不要向 Issue 上传订阅链接、节点凭据、管理密钥、私有配置或内部截图。

### 第三方组件与对应源码

主项目采用 MIT 许可，内置 mihomo 采用 GPL-3.0，其他组件按各自许可分发。对应源码及来源随本次 Release 提供：

- `CORE-ORIGIN.json`：实际核心版本、二进制摘要和上游来源。
- `MIHOMO-COMPONENTS.json`：实际核心的 Go 组件及许可清单。
- `mihomo-source-v1.19.33.tar.gz`：固定版本 mihomo 对应源码。
- `mihomo-dependencies-v1.19.33.tar.gz`：对应 Go 模块源码。
- `openai-proxy-kit-0.4.2-source.tar.gz`：本项目发布提交的完整源码；GitHub 也提供标签源码下载。

请保留这些附件及包内第三方许可。具体组件许可与源码获取说明见仓库的 NOTICE 和第三方组件目录。

卸载命令：`sudo apt remove openai-proxy-kit`。私有配置及恢复备份保留，卸载前可先通过软件关闭代理。
